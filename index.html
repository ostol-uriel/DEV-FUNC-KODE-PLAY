Before You Install

Purpose

Moves data from a PostgreSQL source to a MongoDB target, then keeps applying new inserts, updates and deletes until you're ready to finish. Foreign keys become embedded documents or references, and the data is verified before you complete the migration.

Intended Users

Database operators, database administrators, migration administrators and technical users who monitor and complete a migration.

Basic database knowledge (host, port, schema, collection) is all you need.

Client System

A 64-bit Windows or Linux computer running the installer, portable app or AppImage, with:

  • Permission to install or run the app
  • A reliable internet connection
  • Correct system date and time
  • Access to any required VPN

Network Requirements

The GRASYA cloud service must reach both databases, not just your desktop:

  • Database hosts and ports are reachable
  • Firewall, trusted-IP and VPN rules are active
  • TLS certificates are valid
  • Accounts may connect from GRASYA

Avoid localhost unless your provider set up a tunnel.

Cloud services are run by the GRASYA provider. See what connection details to collect in the Manual →
